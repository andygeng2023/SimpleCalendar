# Daymark / SimpleCalendar

A clean, responsive calendar and task list built with plain HTML, CSS, and JavaScript.

## Features
- Home screen with today's date, to-do and completed events.
- Month, week, and all-dates calendar views with current-day outline and selected-day highlight.
- Search events by title, description, location, or ISO date.
- Quick add with rule-based parsing for common dates, times, and repeat phrases.
- Full event editor for title, description, location, people, start/end time, repeat, and notes.
- Mark events complete, edit/delete events, and recurring daily/weekly/monthly/yearly events.
- Local browser storage; no account or server required.
- Responsive layout and fixed bottom navigation.

## Run
Open `index.html` in a modern browser, or serve this directory with any static file server.

Events are stored in the browser's localStorage. Clearing browser storage removes locally saved events. This app does not yet sync across devices or send invitations/reminders.
